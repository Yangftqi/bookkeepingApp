# 基米记账 (BookkeepingApp)

一款**纯本地离线优先（SQLite）**、跨平台（Android / iOS / Windows 一套代码）、支持**多用户 4 级权限与超级管理员主 PIN 码**、**高刷深度视觉主题定制**、**宏观经济学双引擎建模对比**与**三大原生协议大模型流式分析**的支出记账应用。

---

## 核心特性

### 1. 多用户与 4 级安全权限体系
- **超级管理员主 PIN 码**：首次启动引导设置 4~6 位数字主 PIN 码并创建首个用户；主 PIN 码可万能解锁任意子用户、重置遗忘的子用户 PIN 码以及执行整机全量备份/还原。
- **4 级独立保护状态机**：每个子用户可独立配置 `0: 无密码` / `1: 删改保护` / `2: 增删改保护` / `3: 增删改查全保护`。
- **防锁死与防越权**：级别 3 冷启动锁屏右上角常驻「切换其他用户」入口；所有敏感操作均严格按当前登录用户身份校验，杜绝跨用户越权。

### 2. 高效记账、多维筛选与纯净赏图
- **内置四则运算计算器键盘**：原生支持 `+`、`−`、`×`、`÷`、小数与实时算式求值，单手快速记账。
- **同日「工作日 / 休息日」全局事务绑定**：同一用户同一自然日下的所有账单自动共享「工作日 / 休息日」状态，修改任意一条即自动事务同步当日全部记录。
- **组合筛选与批量管理**：支持按备注关键词、日期预设/自定义区间、多选类别（含常驻兜底「未分类」）、工作日/休息日属性筛选，支持按时间/金额排序、顶部实时汇总与批量改类别/批量删除。
- **双列表形态 + 下拉纯净赏图**：
  - **插画卡片模式**：采用方向性渐变遮罩 + 左侧紧凑统一磨砂信息块（类别 / 时间 / 备注）+ 右下角同款磨砂金额块，在复杂插画背景上依然高对比度易读，同时完整留出中间插画视野；支持切换「胶囊角标」或「45° 斜角丝带」。
  - **超紧凑极简模式**：单行高密度卡片配右侧竖排日型色条，兼顾浏览效率与通透全局背景展示。
  - **低阻尼下拉纯净赏图**：在账单页列表顶部轻拉即可进入纯净赏图模式，完整欣赏全局背景图（上划或点击退出返回）。

### 3. 纯图表聚焦统计（日 / 周 / 月）
- **交互式分类占比饼图**：支持点击扇区高亮显示对应分类占比与金额，配合简洁分类排行榜。
- **可锁定数值趋势图**：支持 24 小时 / 周一至周日 / 全月趋势浏览，单击数据点锁定顶部数值胶囊。
- **自然日分母工作日 vs 休息日对比**：严格按时段内自然日天数计算工作日与休息日的自然日均消费及假日消费倍率。

### 4. 宏观经济学洞察 & 双引擎 API 建模
- **内置恩格尔系数 (Engel's Coefficient)**：预置联合国 FAO 6 级标准与 37 个国家/地区基准数据，支持动态勾选分子类别、切换「时段总支出 / 手动基数」分母，自动计算所处评级与样本库分位排行。
- **引擎 1（AI 结构化建模）**：输入任意统计主题，按严格 JSON Schema 一键生成指标定义、评级区间与 20~30 个代表性基准样本。
- **引擎 2（World Bank / 自定义 REST JSON 直连）**：支持直连 World Bank Open API v2 或任意自定义 JSON 接口清洗入库。
- 支持将当前对比快照「一键交给 AI 深度解读」。

### 5. AI 账单分析师（三大原生协议 & 9 套角色库）
- **三大原生大模型协议**：原生支持 **OpenAI 兼容接口**（DeepSeek / OpenAI / 通义千问 / 硅基流动 / 本地 Ollama 等）、**Google Gemini 原生协议** 与 **Anthropic Claude 原生协议**。
- **多套 API 配置与模型列表搜索**：支持保存多套 API 配置一键切换、主动拉取并搜索远端模型列表与测试连接。
- **SSE 流式多轮对话与 9 套预置角色**：内置 **3 套专业理性角色**（「理性经济学家」「毒舌省钱搭子」「温和财务规划师」）与 **6 套二次元特色陪伴角色**（「同居粘人猫娘」「操心萝莉妈妈」「模型同好温柔学妹」「傲娇大小姐管家」「冷面机娘秘书」「慵懒狐仙姐姐」），全部支持自由编辑/删除/模板找回，对话历史按用户本地隔离保存。

### 6. 深度主题工坊 & 主题包生态 (`.themepkg.zip`)
- **高刷零卡顿渲染架构**：全工程摒弃逐帧 `BackdropFilter`，采用 `RepaintBoundary + ImageFiltered` 静态纹理缓存 + 纯透明混合高透轻玻璃，在 60/120Hz 高刷屏上保持丝滑流畅。
- **全维度可视化定制**：
  - 支持全局背景图（9:16 或自由比例）与各类别卡片底图（16:5，含「未分类」）交互式裁剪，提供「保留无损原图」与默认智能高清压缩（全局 ≤2560px JPEG 90%，卡片 ≤1280px JPEG 85%）切换；
  - 支持调节**高透玻璃颜色与不透明度**、**强调文字是否跟随主题主色**（关闭后累计支出等高亮数字跟随深/浅文字色切换，确保高对比度）、工作日/休息日边框实虚线与胶囊/斜角丝带；
  - 主题编辑器顶部**吸顶常驻实时预览**，支持随时切换插画/极简与工作日/休息日即时调参。
- **零浪费候选样式库 (`cardStylePool`)**：导入主题包时自动同名绑定类别，多余/备用皮肤自动收录进主题候选库，可在编辑器中与任意本地类别双向一键绑定。
- **主题包制作规范索引**：
  - 如果你想自己制作、分享或使用 AI 生成兼容本应用的 `.themepkg.zip` 主题包，请查阅完整规范文档：**[《「基米记账」主题包制作与美学设计规范 (theme_package_specification.md)》](theme_package_specification.md)**（涵盖 ZIP 目录约束、`theme.json` 全字段字典、图层渲染公式、构图安全区法则、黄金参数配方及 Python 一键打包脚本）。

### 7. 三级 `.zip` 跨设备导入导出 & 手动离线更新检查
- **单用户数据包 (`.userpkg.zip`)**：支持按类别名自动补齐、按 UUID 去重合并 / 覆盖 / 作为新用户导入。
- **主题包 (`.themepkg.zip`)**：打包完整配色与图片资源，支持缺失类别一键创建或仅收入候选库。
- **整机全量备份包 (`.fullbackup.zip`)**：需验证超级管理员主 PIN 码，支持 Android ↔ Windows 100% 完整迁移还原。
- **严格离线优先**：绝不在启动时静默联网；设置页提供手动触发的 GitHub 新版本检查入口。
