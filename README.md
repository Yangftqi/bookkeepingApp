# 基米记账 (BookkeepingApp)

一款纯本地离线优先、多用户 4 级权限、深度视觉主题定制、支持宏观经济学模型对比（含双引擎 API 建模）与 OpenAI 兼容大模型流式对话分析的跨平台支出记账应用（Android / iOS / Windows）。

## 核心特性

- **多用户与 4 级安全状态机 + 超级管理员主 PIN 码**
  - 首次启动强制设置 4~6 位数字超级管理员主 PIN 码并创建首个用户。
  - 主 PIN 码可万能解锁任意子用户、重置子用户遗忘的 PIN 码以及执行整机全量备份/还原。
  - 每个子用户独立支持 4 级保护：`0: 无密码` / `1: 删改保护` / `2: 增删改保护` / `3: 增删改查全保护`（冷启动锁屏自带「切换其他用户」防锁死入口），并严格防止跨用户越权操作。
- **四则运算记账与同日「工作日 / 休息日」全局绑定**
  - 内置完整四则运算计算器键盘（`+`、`−`、`×`、`÷`、小数与实时算式求值）。
  - 同一用户同一自然日下的所有账单强制共享「工作日/休息日」状态，修改任一条后自动事务同步当日全部账单。
  - 支持备注关键词、起止日期、多选类别（含常驻兜底「未分类」）、工作日/休息日属性组合筛选、排序、实时汇总与批量改类别/批量删除。
- **纯图表聚焦统计（日 / 周 / 月）**
  - 环形分类占比饼图（点击扇区高亮显示，不弹干扰抽屉）与分类排行榜。
  - 24 小时 / 周一至周日 / 全月趋势图。
  - 严格按**自然日天数分母**计算的工作日 vs 休息日自然日均消费与假日消费倍率。
- **宏观经济学洞察 & 双引擎 API 建模**
  - 内置「恩格尔系数 (Engel's Coefficient)」模型、联合国 FAO 6 级标准与 37 个国家/地区基准数据。
  - 动态勾选分子类别、自由切换「时段总支出 / 手动基数」分母、自动计算标准评级区间与样本库分位排行。
  - **引擎 1（大模型 AI 结构化生成）**：输入任意统计主题，按严格 JSON Schema 一键生成指标定义、评级区间与 20~30 个代表性基准样本。
  - **引擎 2（世界银行 Open API / 自定义 REST JSON 直连）**：直连 World Bank v2 API 或任意自定义 JSON 接口清洗入库。
  - 支持「一键交给 AI 深度解读」。
- **AI 账单分析师（SSE 流式多轮对话 & 9 套预置分析角色库）**
  - 全局共享 OpenAI 兼容接口配置（内置 DeepSeek / OpenAI / 通义千问 / 硅基流动 / 本地 Ollama 模板与测试连接）。
  - 每个角色配备简短特色说明标签，内置 **3 套专业理性角色**（「理性经济学家」「毒舌省钱搭子」「温和财务规划师」）与 **6 套性格鲜明的二次元特色陪伴分析角色**（「同居粘人猫娘」「操心萝莉妈妈」「模型同好温柔学妹」「傲娇大小姐管家」「冷面机娘秘书」「慵懒狐仙姐姐」）。
  - 所有角色（含预置角色）均支持自由修改与删除，并提供「套用系统预置模板 / 一键找回缺失预置角色」功能。
  - 支持按用户隔离保存本地多轮对话历史。
- **深度主题工坊与图片分级高清优化**
  - 内置「清爽极简白」与「暗夜星河黑」2 套默认主题。
  - 支持全局背景图（9:16 或自由比例）与各类别卡片底图（16:5，含「未分类」）交互式裁剪、模糊度/遮罩调节、工作日/休息日边框实虚线与角标定制。
  - 内置「保留无损原图」开关（默认关闭采用智能高清优化：全局背景 ≤2560px JPEG 90%，类别卡片 ≤1280px JPEG 85%）。
- **三级 `.zip` 跨设备导入导出**
  - 单用户数据包 (`.userpkg.zip`)：支持按类别名自动补齐、按 UUID 去重合并 / 覆盖 / 作为新用户导入。
  - 主题包 (`.themepkg.zip`)：含背景图资源，导入自动检测缺失类别并询问一键创建绑定。
  - 整机全量备份包 (`.fullbackup.zip`)：需验证超级管理员主 PIN 码，支持 Android ↔ Windows 100% 整机迁移还原。

flutter build apk --release
